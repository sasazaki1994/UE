# PR #17 カメラ改修のmain統合

2026-09-10。main `b5dab85` を取り込み、README、検証履歴、Player、HUD、起動スクリプトの競合を解消しました。

- 大型モデルの地上カメラは、mainの巨体の外側へ700cm・上へ280cm退避する方式を保持。壁際では上方退避を使用します。
- 通常視点への復帰には0.15秒の待機と0.35秒の位置・注視点の補間を適用し、復帰中の遮蔽も検査します。
- 登攀専用カメラを保持し、登攀開始時は地上カメラの復帰状態をリセットします。
- 地上の斬撃方向を水色、進行中の斬撃方向を白色の矢印で表示します。登攀・汎用Grab中は矢印を隠し、既存の浄化・移動操作とスタミナHUDを保持します。
- `Tools/Prototype.ps1 -Action Test -Camera` を追加。旧戦闘配置の検査とは独立して、現行Arenaと大型モデルでカメラと地上攻撃入力を検査します。
