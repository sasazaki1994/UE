# 4. HUD文字を減らす情報提示

状態: 本番UI仕様案 / 置換未実装。現行HUDは新しい手掛かりの可読性が確認できるまで残す。

## 基本方針

長い攻略説明は初回だけ。危険・安全・操作可能状態は、短い表示と世界内の手掛かりを併用する。色、音、振動の一つだけに依存しない。字幕・高コントラスト・警告アイコンは任意で使用できる設計にする。

| ゲーム側の状態 | 世界内の手掛かり案 | 残す短い補助表示 | 注意 |
|---|---|---|---|
| Boundary強度 | 刀身の反応の強さ・間隔 | 「弱／中／強」 | 正確な目的地矢印へ変えない |
| Corruption Danger | 左腕の模様の明滅、低い予告音 | 「危険」＋警告形状 | 激しい点滅・必須振動にしない |
| Corruption Safe | 左腕の反応が落ち着く | 「好機」 | Recoverは反撃機会。無敵や完全な安全を意味しない |
| Corruption Transition | 主・根の姿勢変化と軋み | 「動きが変わる」 | 突然カメラを奪わない |
| Posture減少 | 禍の隆起に亀裂が走る | 「体勢 2/3」等 | 本体HPと呼ばない。反撃ごとの加算／残量の表記を統一 |
| Kneel / Grab可能 | 前脚の輪郭と既存金色マーカー | E / RBと「取り付く」 | 非表示でも入力条件は変えない |
| Shake予告 | 呼吸・身体の予備動作、鈴 | E / RBと「しがみつく」 | 音だけで必須タイミングを伝えない |
| 禍根浄化 | 対象の黒い筋・脈動が消える | 「祓い 1/3」 | 消えた場所と数が対応する |
| Stamina低下 | 最小の共通ゲージ | ゲージと低残量警告 | ゲージを消して難しさを上げない |
| Recovery可能 | 既存の復帰ビーコン | 「戻れる場所」＋任意距離 | 見失いやすい時は文字を残す |

「仮面の刻印が浄化数に応じて点灯する」旧提案は採用しない。仮面に能力を持たせず、不要な衣装・材質差分も増やさない。

## 三つの表示設定案

- 標準: 短文、入力ボタン、Stamina、世界内の手掛かり。
- 補助強化: 標準に加えてSense強度、警告字幕、体勢と禍根数、復帰案内を常に読みやすくする。
- 没入重視: 慣れた人が説明文を減らせる任意設定。初期設定にはしない。初見で必要な情報が消えないか実機確認後に導入する。

既存 `-DebugGuidance` は開発用表示として別に維持する。アクセシビリティ設定の代用にはしない。

## 初回の教え方

石走りへの接近路で移動・カメラ・境断ち、石走り戦で回避・反撃・取り付き・Cling・休息・祓いを順に教える。全部を一画面で説明しない。誤入力や失敗が続く時に短文を再表示する仕組みは将来候補で、新しいチュートリアル基盤を今回要求しない。

## UEでの受入確認

音を消しても危険とGrab機会が分かること、振動なしでも操作できること、色だけで状態を区別させないこと、巨体に隠れた禍根の数を補助表示で補えること。確認前に「文字なしでも攻略可能」とは判断しない。
