# 5. 音響・鎮静演出

状態: 発注仕様。共通6役の素材選定・加工は `Docs/Audio/CommonSfx.md` と
`Audio/CommonSfx/manifest.json` を正本とし、採用素材が揃うまでゲーム実装には接続しない。

## 音の役割

風・水・木・石・呼吸を基調とする。危険を伝える音、操作成功の音、環境音を役割で分け、BGMや禍の低音が操作予告を埋めないようにする。以下の音名は論理イベント名であり、既存APIや納品済みファイル名ではない。

| 論理イベント | 駆動条件 | 音・絵の最小案 | 止める条件 |
|---|---|---|---|
| `BoundaryReading` | 境断ちHoldと検出強度 | 澄んだ反応音の間隔を変える | Hold解除、Retry、Travel |
| `ArmWarning` | 左腕Sense中の警告種別の変化 | 短い低音と左腕の模様 | 同状態の毎Tick再生は禁止 |
| `MountOpen` | 石走りKneel開始／淵纏いSnagged開始 | 短い衝撃音、Grab表示 | 一度のみ、時間切れで残さない |
| `ClingWarning` | 既存の揺れ予告 | 軋み＋鈴＋警告表示 | 揺れ終了、落下、Retry |
| `KakonPurified` | 有効なOnPurifiedを一度受ける | 裂ける禍の音、対象だけ消灯 | 重複操作で再生しない |
| `EncounterCalmed` | 既存Encounter完了通知 | 荒い呼吸が落ち着き、環境音が前へ | Retryで元の状態へ |
| `CorruptionReveal` | Interlude2開始 | 音を抑え、腕と顔の静止画 | カード切替時にループを停止 |
| `FinalPulse` | Ending最終カード／暗転 | 地中の小さな脈動を一度 | Restart後に残さない |

## 主ごとの音色

| 場面 | 戦闘前・最中 | 鎮静後 |
|---|---|---|
| 石走り | 蹄、鼻息、岩の軋み。突進前に地を掻く | 呼吸が遅くなり、土と風の音へ |
| 淵纏い | 水面下の低音、水切り、岩衝突 | 激しい水音が引き、小さな水音へ |
| 峰抱き | 遠雷に似た足音、岩盤の擦れ、腕橋の軋み | 風が身体を抜ける音へ |
| 禍津根 | 根と石の摩擦、地中の周期音 | 動きが止まり、低音が薄れる。人格ある声は使わない |

## 鎮静とゲーム進行を分離する

音や演出の終了を勝利判定に使わない。共通のKakon → Progress → Calm → Completedがゲーム側の正本。浄化・鎮静を演出から再発火させない。

現在のCampaignはCompleted後およそ2秒で次のカードへ進む。初版は主戦中の短い鎮静反応と、次の幕間の静かな画面で余韻を作る。長い専用カットシーンや遷移タイマーの変更はこのパッケージでは行わない。

「全音を消す」表現は演出意図として扱い、警告が必要な戦闘中に全体を強制ミュートしない。瞬間的にBGM・環境音を下げる程度から検証する。耳鳴りの高音、強い低音、振動には音量調整／軽減手段を設ける。

## 白面の二段階と制作上限

EarlyとAdvancedで別の歩行・戦闘モーションや呼吸セットを作らない。必要なら共通の左腕音の音量・フィルタを変えるが、感知の機能・危険の意味は変えない。最終戦と結末にもAdvancedを再利用する。

先行制作は「探知の反応」「左腕の警告」「取り付き好機」「しがみつき予告」「浄化」「鎮静」の共通6役に絞る。主専用の音色とBGMは、その後に必要なものから追加する。商用利用条件・出典が確認できない素材をリポジトリへ入れない。

## 共通6役の納品条件

- 個別音は PCM WAV（48 kHz、16 bit、mono）とし、ファイル名を論理イベント名に合わせる。
- 各素材について元ページURL、作者、ライセンス、原音ファイル、切り出し範囲、音量・音色加工を manifest に残す。ライセンスURLと再配布可否を元ページで確認できない素材は採用しない。
- 6音を表の順で、各音の前に短い間を置いた `CommonSfxPreview.wav` を用意する。プレビューは評価用でありゲームへ取り込まない。
- 検査では WAV のデコード、長さ、無音、peak clipping、RMS の極端な差、manifest と実ファイルの一致を確認する。波形検査は聴感確認の代替にしない。
- 人が実際に試聴していない成果物を「試聴済み」と記録しない。UEへの取り込みとゲーム内再生は別工程とする。
