# 残る3戦の表現更新 — ソース実装段階

3戦は引き続きPrimitiveボスと仮地形を使用する。今回は攻略経路やCollisionに触れず、近接した場所で予告と鎮静が読み取れるようにした。

| 戦闘 | 追加した表示 | 消灯条件 |
|---|---|---|
| 淵纏い | 頭の噛みつき予告・突進、岩への引っ掛かりで低負荷の局所光 | 潜行、鎮静 |
| 峰抱き | 崖登りの開始、揺れ、腕橋・最終経路の変形中に局所光 | 通常移動、鎮静 |
| 禍津根 | 大きな地脈の脈動時に中央核付近の局所光 | 脈動の谷、鎮静 |

いずれも動的ライト1灯、影なし。SenseによるRoute表示、禍根、主の状態遷移、Stamina、カメラには影響しない。音・Niagara・完成モデル・本番マップを生成したという意味ではない。

## UE 5.6.1での確認

この作業環境にはUEがないため、ビルド、Legacy / High Qualityでの白飛び、暗所での読みやすさ、描画負荷、Retry時の消灯は未検証。Windows環境では `Prototype.ps1 -Action Test -Fuchimatoi -Recovery -Capture`、`-Minedaki -Capture`、`-Magatsune -Capture` とCampaignを再実行し、予告直前・動作中・鎮静後を同じ設定で撮影する。明るさは実画像を見て確定する。

完成アートへの移行は [3D制作方針](3DProductionPolicy.md) に沿い、淵纏いの連続した胴、峰抱きの変形する四肢、禍津根の動く地形について、それぞれRouteと禍根の位置を保った実モデルを別途用意する必要がある。
