# 白面の祓い手 / 岩背の巨猪「石走り」 — 3Dモデル

## 2026-09-09 更新

`Shirotsura/Rigged/` と `Ishibashiri/Rigged/` が骨組み・アニメーション・2048pxテクスチャ付きの最新版です。
主人公は10、猪は5クリップ。Blender、アニメーション付きGLB、スケルタルFBXを収録しています。
UEでは `/Game/Characters/Rigged` を使用し、登攀も実装済みです。操作と制限はリポジトリの `README.md` を参照してください。
下記は静止モデル版の説明です。リグ・アニメーション未制作という記述は静止モデルにのみ該当します。

提供された設定画と設定文をデザイン資料として制作した、スタティックな形状検討モデルです。
画像そのものではなく、編集可能な立体メッシュを収録しています。写実的な完成モデルではありません。

## 開くファイル

- `Shirotsura/Shirotsura.blend`：主人公。白木の面、濃紺の作業着、生成りの布、腰縄、異形の左腕、刀と鞘。
- `Ishibashiri/Ishibashiri.blend`：巨猪。石の牙、肩岩、段状の岩棚、苔、注連縄、3つの禍根。
- 同名の `.glb`：色付きで受け渡す汎用形式。
- 同名の `.fbx`：UE等へのスタティックメッシュ取り込み用。
- `Previews/`：モデルから実際にレンダリングした正面寄り・背面・上面画像。
- `CharacterScaleComparison.blend`：同じ縮尺で両モデルを並べたシーン。
- 各フォルダーの `model-info.json`：寸法、三角形数、メッシュ数。

Blender 3.6.23で作成。Blender内はメートル、Zが上、-Yが正面です。
主人公の身長は約1.72m。巨猪の全長は約12.2m、樹木を含む高さは約9.4m。
FBXはメートル単位情報を含みます。UE取り込み後の寸法は `ue-import-report.json` で確認できます。

## 今回の範囲

仮面、刀、服、根、岩棚などを名前付きの部品に分けています。
岩棚の候補位置、主ルート、分岐、禍根の座標は `Ishibashiri/climb-layout.json` に記録しています。
岩棚の形状と配置は視覚検討用で、Grab / Climbingによる到達・カメラ・衝突の実プレイ検証はまだ行っていません。

リグ、スキニング、アニメーション、LOD、製品用UV・ベイク済みテクスチャは未制作です。
Blenderの細かなノイズ凹凸はプロシージャルシェーダーです。GLB/FBXでは色を主体とした表示になります。
UEでのマテリアル変換、特に発光や凹凸はBlenderの表示と一致するとは限りません。
曲線は書き出し前にメッシュへ変換済み。部品同士が重なる組み立てモデルで、3Dプリント用の一体ソリッドではありません。

## UE確認レベル

`Content/Maps/L_CharacterStudies.umap` にスタティックな比較用レベルを作成済みです。
既存の戦闘プロトタイプへのキャラクター置換は行いません。
`Tools/ImportCharacterStudies.py` はこの専用レベルと `/Game/Characters/DesignStudies` のみを再生成します。
UEのImport処理と寸法を検証し、UE上の描画・プレイは未検証として区別します。
取り込みは正常終了しました。エンジン起動時には、既存のゲームモジュールが参照する旧 `FreeModels` アセットの欠落警告が別途出ています。

## 再生成

リポジトリ直下から実行します。

```powershell
& 'Saved/ModelDownloads/Blender/blender-3.6.23-windows-x64/blender.exe' --background --factory-startup --python Tools/CreateCharacterModels.py
```

片方のみ再生成する場合は末尾へ `-- hero` または `-- boar` を追加します。
このスクリプトは専用の成果物を上書きします。手作業で編集する場合は別名保存してください。
制作に外部の3Dメッシュやダウンロード済みの猪モデルは使用していません。
