# Story-card artwork

## Interlude2 — after Fuchimatoi

- `Interlude2_AfterFuchimatoi.png` is the text-free 1920 × 1080 (16:9) card artwork, stored through Git LFS so the review diff remains text-only.
- `Previews/Interlude2_AfterFuchimatoi_Layout.svg` is a review-only overlay of the current `CampaignHUD.cpp` heading, first Interlude2 body line, and continue prompt. It is not a runtime asset.
- The subject uses the existing Shirotsura reference design: white ritual mask, layered dark robes, red cords, `Advanced` left-arm corruption, and no added horns or mask ability.
- The left and center remain dark and quiet so the existing centered HUD copy stays readable.

The PNG was produced as a reference-guided original raster composition from `Art/Characters/Shirotsura/References/Front.png` and `Turnaround.png`. No text is embedded in the PNG. Unreal Engine display validation has not been performed because UE is unavailable in the production environment.
